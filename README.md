# Smart City Bike Sharing Data Analysis using Power BI

## Project Overview
This project analyzes a smart city bike-sharing dataset using Microsoft Power BI to understand bike station distribution, parking capacity, bike availability, and station operational status across different cities.

## Objectives
- Analyze bike station distribution across cities.
- Compare total bike-stand capacity and bike availability.
- Monitor open and closed station status.
- Explore recorded bike availability trends over time.
- Build an interactive dashboard to support data-driven decisions.

## Tools & Technologies
- **Microsoft Power BI** – Dashboard creation and data visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Calculated measures and analytical calculations
- **Data Modeling** – Fact tables, dimension tables, and relationships
- **Excel** – Source dataset

## Data Preparation
- Imported the Excel dataset into Power BI Desktop.
- Inspected data types, missing values, duplicates, and text consistency.
- Prepared fact and dimension tables.
- Established relationships between tables.
- Created KPI cards, charts, slicers, and interactive dashboard visuals.

## Key Insights
- Lyon has the highest number of stations and total bike-stand capacity among the cities displayed.
- The dashboard summarizes 1,082 stations, including 941 open stations (86.97%) and 141 closed stations (13.03%).
- Bike availability and empty stand capacity vary across cities.
- Recorded bike availability increases sharply in 2025 compared with 2022–2024; further validation is needed to understand this pattern.

## Recommendations
- Review cities with lower station coverage and bike availability.
- Investigate frequently closed stations and unusual capacity patterns.
- Monitor bike availability and station status regularly.
- Improve bike distribution based on station capacity and demand-related indicators.
- Incorporate trip counts, revenue, distance travelled, and operating costs for further operational and financial analysis.

## Conclusion
This project demonstrates how Power BI can transform bike-sharing data into meaningful insights about station infrastructure, capacity, and operational status. The dashboard supports better monitoring and helps identify opportunities to improve bike distribution and station management.
